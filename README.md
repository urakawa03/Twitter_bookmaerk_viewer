# X ブックマーク・ローカルビューア

twitter-web-exporter がエクスポートした X（旧Twitter）ブックマークの CSV / JSON を、ローカル環境で長期保管・閲覧するためのビューアです。詳細な仕様は [viewer-spec.md](viewer-spec.md) を参照してください。

## 使い方（Web アプリ・推奨）

GitHub Pages で配信される固定 URL をブラウザで開くだけです：

**https://urakawa03.github.io/Twitter_bookmaerk_viewer/**

- ブックマークデータはこの URL に紐づく**あなたのブラウザ内（IndexedDB）にのみ**保存されます。サーバーには何も送信されません
- **アプリを更新（git push）してもデータは消えません**。URL が同じである限り、ブラウザ内のデータは同じ場所に残り続けるためです
- PWA 対応: 一度開けばオフラインでも起動でき、ブラウザのメニューから「ホーム画面に追加 / インストール」してアプリのように使えます
- 初回デプロイのみ、リポジトリの Settings → Pages → Source を「GitHub Actions」にする必要がある場合があります（以後は push するだけで自動デプロイ）

### file:// で使っていたデータの引っ越し

ローカルの `index.html` を直接開いて使っていた場合、データはその「開き方」に紐づいているため、Web アプリ側からは見えません。一度だけ次の手順で移行してください：

1. 今まで通り古い `index.html` を開く → データ管理 → **バックアップをダウンロード**
2. Web アプリの URL を開き、その JSON を**ドラッグ&ドロップ** → 件数・フォルダ・割当がすべて復元されます

## 使い方（ローカル単体）

従来通り **`index.html` をダブルクリックで開くだけ**でも動きます。ビルド・サーバー・アカウント一切不要。ただしデータはファイルの場所とブラウザに紐づくため、ファイルを移動・改名・差し替えするとデータが見えなくなることがあります。長く使うなら Web アプリ版＋定期バックアップを推奨します（30日以上バックアップがないと起動時にリマインドが出ます）。

1. twitter-web-exporter の Bookmarks CSV（または JSON）をウィンドウにドラッグ&ドロップ（または「取込」ボタンから選択）
2. 「新規 n 件 / 重複 m 件」が報告され、ブラウザの IndexedDB に保存されます
3. 以後はファイルを開くだけで書庫を閲覧できます

## 主な機能

- **取込・マージ**: CSV / JSON（通常・metadata 付き・本アプリのバックアップ）を自動判別。ツイート ID で突合し新規のみ追加。エクスポート期間が重なっても安全
- **閲覧**: 段階描画で大量件数でも軽快。改行保持・URL 自動リンク・ハッシュタグ強調・`twitter.com` → `x.com` 正規化・日付は JST（元オフセット）表記
- **メディア**: 画像は原寸リンク付きサムネイル、動画・GIF はクリックでその場再生（mp4 直リンク）。404 は自動で畳む
- **引用ポスト**: metadata 付き JSON から抽出した引用データ（作者・全文・メディア）→ 書庫内相互参照 → 外部リンク付きプレースホルダの優先順で入れ子表示
- **検索・絞り込み・ソート**: 本文・名前・ハンドルのインクリメンタル検索、メディア / 引用 / 長文 / ユーザー絞り込み、日付・いいね数ソート
- **フォルダ分類**: ユーザー定義フォルダへの単一割当。追加・改名・削除・並べ替え（データ管理の ↑↓）、タブ切替、件数バッジ。`知識系/プログラミング` のように「親/子」で名付けると1階層のサブフォルダになり、親タブは子を含めて集計表示
- **閲覧位置の記憶**: 検索語・絞り込み・ソート・選択タブ・スクロール位置を自動保存し、リロードしても同じ状態・位置から再開
- **整理モード**: 未分類を1件ずつ全画面表示し、数字キー 1〜9 で割当 / Enter でスキップ / ← で取り消し / Esc で終了
- **バックアップ / 復元**: 書庫全体（アイテム・フォルダ定義・割当・取込履歴）を JSON で入出力。フォルダ割当は CSV 再取込でも消えません

## プライバシー

ローカルファースト。外部通信は twimg.com からのメディア取得のみで、テレメトリや外部送信は一切ありません。テキスト閲覧はオフラインで完結します。

## 動作環境

IndexedDB が使えるモダンブラウザ（Chrome / Edge / Firefox / Safari）。ストレージが使えない環境では警告を表示した上で、メモリ上での閲覧のみ可能です。
