# X ブックマーク・ローカルビューア

twitter-web-exporter がエクスポートした X（旧Twitter）ブックマークの CSV / JSON を、ローカル環境で長期保管・閲覧するためのビューアです。詳細な仕様は [viewer-spec.md](viewer-spec.md) を参照してください。

## 使い方

**`index.html` をブラウザ（Chrome / Edge 推奨）でダブルクリックで開くだけ**です。ビルド・サーバー・アカウント一切不要。

## データファイル連携（推奨・アップグレード対策）

アプリの作業データは通常ブラウザ内部（IndexedDB）にあり、HTML の差し替えや移動で「見失う」ことがあります。**データ管理 → データファイル連携**で保存先を一度選ぶと、書庫全体（アイテム・フォルダ定義・割当・取込履歴）が**手元の JSON ファイルに自動保存**されるようになり、この問題を根本解決できます：

1. データ管理 → 「**データファイルを新規作成**」→ 保存先を選ぶ（例: `Documents/x-bookmarks-data.json`）
2. 以後、取込やフォルダ割当のたびに自動でそのファイルへ書き込まれます
3. `index.html` を新しいものに差し替えたら、データ管理 → 「**既存ファイルを開く**」で同じファイルを選ぶだけで全復元
4. ブラウザの確認バナーが出た場合は「再接続」を押してください

- データファイルは**重複排除済みの書庫そのもの**です。重複だらけのエクスポートを何度取り込んでもファイルは太りません（取込履歴も最新100件まで）
- エクスポーターから受け取る JSON（取込用・読むだけ）とは**別物**です。取込用ファイルは取り込んだら捨てて構いません
- ファイルをコピーすればそのままバックアップになります。「書庫を全削除」してもこのファイルは消しません
- File System Access API を使うため **Chrome / Edge 限定**です（他ブラウザは従来の IndexedDB＋手動バックアップ運用。30日以上バックアップがないと起動時にリマインドが出ます）

## Web アプリとして使う（任意）

固定 URL で配信すればブラウザ内データも URL に紐づいて安定します。GitHub Pages 用のワークフローを同梱していますが、**プライベートリポジトリのままでは GitHub 無料プランで Pages を使えません**（公開リポジトリにするか、有料プラン、または Cloudflare Pages / Netlify の無料枠を利用）。PWA 対応済みのため、配信すればオフライン起動・ホーム画面インストールも可能です。

1. twitter-web-exporter の Bookmarks CSV（または JSON）をウィンドウにドラッグ&ドロップ（または「取込」ボタンから選択）
2. 「新規 n 件 / 重複 m 件」が報告され、ブラウザの IndexedDB に保存されます
3. 以後はファイルを開くだけで書庫を閲覧できます

## 主な機能

- **取込・マージ**: CSV / JSON（通常・metadata 付き・本アプリのバックアップ）を自動判別。ツイート ID で突合し新規のみ追加。エクスポート期間が重なっても安全
- **閲覧**: 段階描画で大量件数でも軽快。改行保持・URL 自動リンク・ハッシュタグ強調・`twitter.com` → `x.com` 正規化・日付は JST（元オフセット）表記
- **メディア**: 画像は画面の解像度に合わせた版を自動選択（高DPIディスプレイでもぼやけません）。**クリックで同じタブ内に拡大表示**（← → で複数枚を送る／Esc で閉じる／原寸を別タブで開くリンクつき）、動画・GIF はクリックでその場再生（mp4 直リンク）。404 は自動で畳む
- **ギャラリー表示**: ヘッダの「▦ ギャラリー」で、いま絞り込んでいる投稿の写真・動画をサムネイルの格子で一覧できます（**画面幅いっぱい・最大5列**、狭い画面では自動で列を減らします）。「写真・動画 / 写真のみ / 動画のみ」で種類を絞り込め、写真をクリックすると**絞り込み範囲の全写真を ← → で送れる**拡大表示になります
- **投稿パネル（ギャラリーのまま本文を読む）**: 拡大表示の脇（スマホでは下）に、その写真の投稿そのもの——作者・日付・**本文**・引用・反応数・元の投稿リンク・**フォルダ割当**・**メモ**——を出せます。**リスト表示に戻らずに読み、分類し、メモを書けます**（割当やメモはカードと同じ実体なので、タブの件数バッジもその場で変わります）。バーの「ⓘ 投稿」または `I` キーで開閉でき、設定は記憶されます。各タイルの隅の `ⓘ` からこの状態で直接開けます（**動画タイルの `ⓘ` でも本文が読め**、「▶ この動画を再生」でミニプレーヤーに渡せます）。リスト表示で見たいときは「リストで開く」
- **ミニプレーヤー**: 再生中の動画は**常に1本だけ**。カードが画面外へ出たり、タブを切り替えたり、一覧が描き直されても**止まらず**、画面左上の小窓に移って再生を続けます（枠が画面に戻れば自動でカード内へ復帰）。小窓は**クリックで一時停止 / 再開**、`✕` または `Esc` で停止、タイトルバーのドラッグで移動、`⤢` で大きさ変更、`↩` で再生中の投稿へジャンプ。`⧉` はブラウザのピクチャーインピクチャーで、**別のタブに移っても映像を残せます**（対応ブラウザのみ。非対応でも音声はそのまま続きます）。小窓の位置と大きさは記憶されます
- **引用ポスト**: metadata 付き JSON から抽出した引用データ（作者・全文・メディア）→ 書庫内相互参照 → 外部リンク付きプレースホルダの優先順で入れ子表示
- **検索・絞り込み・ソート**: 本文・名前・ハンドルのインクリメンタル検索、メディア / 引用 / 長文の絞り込み。カードの `@ハンドル` をクリックすると、そのアカウントの X ホームが別タブで開きます。並び替えは投稿日（新旧）・**ブックマーク順**（エクスポートの並び順から推定）・**分類した順**・いいね数・**ランダム**（「🔀 シャッフル」で並べ直し。同じ並びはリロードしても保たれます）
- **ゴミ箱**: カードの 🗑 で一覧から隠せます（**データは削除されず**、JSON にも残ります）。ゴミ箱タブから中身を確認し、「↩ 復元」でいつでも戻せます
- **フォルダ分類**: ユーザー定義フォルダへの単一割当。追加・改名・削除・並べ替え（データ管理の ↑↓）、タブ切替、件数バッジ。`知識系/プログラミング` のように「親/子」で名付けると1階層のサブフォルダになり、親タブは子を含めて集計表示
- **閲覧状態と位置の記憶**: 検索語・絞り込み・ソート・選択タブ・表示モード（リスト / ギャラリー）に加え、**タブごとに最後に見ていた投稿**を記録します。「すべて」を途中まで読む→別のフォルダタブを読む→戻ると、それぞれの続きから再開できます（座標ではなく投稿IDで覚えるアンカー方式なので、段階描画や画像の読み込みでズレません）。初めて開くタブや、並び替え・絞り込みを変えた直後は先頭から。データ管理 → 表示 でオフにすると常に先頭から表示します
- **整理モード**: 未分類を1件ずつ全画面表示し、数字キー 1〜9 で割当 / Enter でスキップ / ← で取り消し / Esc で終了
- **メモ**: カードの「📝 メモ」からその場で短いメモを書けます（フォルダとは別レイヤー）。フォーカスを外すか `Ctrl`／`⌘`+`Enter` で保存、`Esc` で取消。ヘッダの「メモ」で絞り込め、検索もメモ本文を対象にします
- **Obsidian へ出力**: 「📤 出力」からメモ付きポストをまとめて書き出します。詳細は下記
- **バックアップ / 復元**: 書庫全体（アイテム・フォルダ定義・割当・取込履歴・メモ）を JSON で入出力。フォルダ割当とメモは CSV 再取込でも消えません

## Obsidian（40_Materials）へ出力

「📤 出力」で、メモを書いたポストを **`40_Materials/2026.md` にそのまま追記できる書式**にまとめ、クリップボードにコピー（または `.md` でダウンロード）します。

```
08-22 蒸留の話、教師モデルの出力を全部使わず上位k個に絞る手法。
      うちのケースでも隠れ層を絞る前にこれを試す余地がある
      > 知識蒸留で全ロジットを使うのは実は無駄が多くて、上位k個に絞っても精度は…
      @someone https://x.com/someone/status/1001
```

- 日付は**メモを書いた日**。1行目がメモ、以降は6スペース字下げで原文の冒頭（既定150字・変更可）と出典 URL が続きます
- **出力してもメモは消えません。** 出力日の印が付き、既定の出力対象は「未出力のみ」なので二重に貼ることがありません
- 出力後にメモを書き足すと「出力後に編集したもの」として再び出せます。**思考の変化だけを追記**できます
- 出力対象は「いま絞り込んでいる範囲だけ」にも限定できます。ゴミ箱の中身は常に対象外です
- 誤って印を付けたときは「直前の印を取り消す」で戻せます

## プライバシー

ローカルファースト。外部通信は twimg.com からのメディア取得のみで、テレメトリや外部送信は一切ありません。テキスト閲覧はオフラインで完結します。

## 動作環境

IndexedDB が使えるモダンブラウザ（Chrome / Edge / Firefox / Safari）。ストレージが使えない環境では警告を表示した上で、メモリ上での閲覧のみ可能です。
