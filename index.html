    書庫を手元の JSON ファイルへ自動保存します。アプリ（HTML）を差し替えても データはこのファイルに残り、次回起動時に自動で読み込まれます。（Chrome / Edge 対応）

    バックアップ / 復元

    書庫全体（アイテム・フォルダ定義・割当・取込履歴）を JSON で保存します。 復元は書き出した JSON をドロップまたは「取込」から読み込むだけです。
